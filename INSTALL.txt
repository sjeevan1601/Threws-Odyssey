WANDERWAYS CHATBOX — install in your existing project

1. Copy chat-api.js beside your existing server.js.
2. Copy public/travel-chat.js into your existing public folder.
3. In server.js, add this line with the other imports at the top:

   import { registerChat } from './chat-api.js';

4. Immediately AFTER app.use(express.json({ limit: '20kb' })); add:

   registerChat(app);

5. In public/index.html, immediately before </body>, add:

   <script src="travel-chat.js" defer></script>

   You may add the same tag to public/explore.html for chat on that page too.

6. Keep your real GEMINI_API_KEY and GEMINI_MODEL in your existing .env.
   This add-on reads them. No keys are packaged or needed in HTML.
7. Save files. Stop the server with Ctrl+C and run npm.cmd start.
8. Open http://localhost:3000 and press Ctrl+F5.
   Click Chat about your trip at the bottom right.

No additional npm packages are needed. Uses Node.js 20+ built-in fetch.
This add-on is for the existing Express project with type: module.
Conversation stays in memory and clears on refresh. The last five exchanges
are sent as context. AI replies are plain text. Hotel lookup is not called by chat.
Your previous Gemini authentication error must be resolved for AI replies.
Live responses have not been verified with your account. Missing-key and input
validation paths can run without provider credentials.
